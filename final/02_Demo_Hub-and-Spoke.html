Hub-and-Spoke / Governance

Bản này dùng Gemini API và bộ kiểm tra Python thật, cần server trên máy.

  1. Mở NLTS/real-demo/cau-hinh-api.cmd, nhập key Gemini của bạn.
  2. Mở NLTS/real-demo/start.cmd và giữ cửa sổ server chạy.
  3. Bấm mở hệ thống bên dưới. Nếu server đang chạy, chỉ cần bước này.
Mở hệ thống →

Key chỉ lưu trên máy trong .env, không nhập vào HTML. Không có kết quả mô phỏng tự thay thế khi chưa có key hoặc API lỗi.
